# GTM 平台调研：依附大平台做小游戏/小程序

> 调研日期：2026-06-04
> 状态：初稿，部分数据基于行业知识（已标注），待 Luna 补充判断

## TL;DR

**推荐路径：微信小程序（非小游戏类目）做 ABTI 人格测试，测试类小程序 + 社交裂变是最快切入点。** 抖音适合做第二平台但准入门槛更高。小红书没有小游戏生态但可以做内容引流。

---

## 1. 抖音小游戏

### 准入门槛
- **主体要求**：企业资质（个体工商户可，个人不行）[行业知识]
- **版号**：2024 年起抖音小游戏逐步收紧，商业化小游戏需要版号或 IAA 备案 [行业知识]
- **资质**：需要《网络文化经营许可证》或《增值电信业务经营许可证》等，具体看类目 [行业知识]
- **⚠️ 对我们的门槛**：需要企业主体。Luna 如果没有公司，这是第一个 blocker

### 分成比例
- **IAA（广告变现）**：开发者拿广告收入的 50-60%（平台抽 40-50%）[行业知识，不确定最新比例]
- **IAP（内购变现）**：平台抽成约 30-50%，具体取决于合作等级 [行业知识]
- **对比 App Store 30%**：抖音抽成更高，但流量免费获取

### 技术栈
- 基于 Canvas + JS 开发，类似 H5 游戏
- 抖音提供开发者工具（类似微信开发者工具）
- 支持 Cocos Creator、Unity（导出小游戏包）等引擎
- **纯前端 H5 也可以**，测试类产品不需要复杂引擎

### 流量优势
- 抖音 DAU 7亿+ [行业知识，2024-2025 数据]
- 小游戏入口：信息流广告、搜索、侧边栏、视频挂载
- **测试类内容天然适合短视频传播**——"测测你的 AI 人格" 这种标题点击率高

### 成功案例
- 各种"合成大西瓜"类休闲小游戏爆过 [已知]
- AI 测试类小游戏在抖音上尚属蓝海 [行业知识]
- MBTI/性格测试类内容在抖音短视频端流量巨大

## 2. 微信小游戏/小程序

### 准入门槛 [部分来源: developers.weixin.qq.com, 已验证]
- **注册**：在 mp.weixin.qq.com 注册小程序账号
- **主体类型**：个人/企业/个体工商户均可注册
- **小游戏 vs 小程序**：
  - 小游戏 = 小程序的"游戏"类目，审核更严
  - 小程序 = 通用类目，测试/工具类走小程序即可，门槛更低
- **发布流程** [已验证]：
  - IAA 游戏：预计 13-37 个工作日
  - IAP 游戏：预计 9-22 个工作日
  - 纯小程序（非游戏）：通常 1-7 个工作日
- **微信认证**：企业主体 300 元/年 [行业知识]
- **个人主体限制**：可发布，但不能开通支付（无法直接收费）

### 分成比例
- **广告组件**：激励视频广告开发者分成约 50-70%（阶梯制，流水越大分成越高）[行业知识]
- **虚拟支付**：安卓端平台抽 40%（2024 年调整后），iOS 端更高 [行业知识，不确定最新]
- **小程序（非游戏）内嵌 H5 付费**：可以走微信支付，手续费 0.6%，**远低于游戏类目抽成**

### 技术栈
- 微信小程序：WXML + WXSS + JS（类 Vue 语法）
- 小游戏：Canvas API + 微信适配层
- 框架：Taro、uni-app（跨平台）、原生
- **ABTI 这种产品用小程序（非小游戏）就够了**，不需要走游戏类目

### 流量优势
- 微信 MAU 13亿+ [行业知识]
- 小程序日活 4.5亿+ [行业知识，2024 数据]
- **社交裂变**：分享到群聊/朋友圈是核心增长引擎
- 测试类小程序分享率极高——"我是 XXXX 型，你呢？"

### 测试类成功案例 [行业知识]
- **网易云音乐年度报告**型 H5——每年刷屏
- **各种 MBTI 测试小程序**——微信搜"MBTI"能搜到大量，说明市场成熟
- **性格测试/心理测试**类小程序持续有流量
- 变现模式：广告 + 付费解锁详细报告 + 社交裂变获客

## 3. 小红书

### 生态现状
- **没有独立小游戏生态**，小红书主要是内容平台 [行业知识]
- 有小程序能力（2024 年开始推）但非常早期 [行业知识]
- **适合做内容引流，不适合做主阵地**

### 变现路径
- 发"AI 人格测试"相关笔记 → 引流到微信小程序
- 适合做种草/测评类内容
- 小红书用户画像（女性为主、消费力强）与人格测试受众高度重合

## 4. ABTI 做小程序可行性评估

### 产品优势
- ✅ 已有完整产品（16 型题目 + 算法 + 结果页）
- ✅ 天然社交传播属性（"你是什么 AI 人格？"）
- ✅ 技术简单（纯前端 + API，不需要复杂引擎）
- ✅ 差异化明确——市面上 MBTI 泛滥，但 **AI 人格测试是新品类**
- ✅ 已有 Web 版本，改造成小程序工作量可控

### 变现模型
1. **免费测试 + 广告**：插入激励视频广告（看广告解锁详细报告）
2. **付费深度报告**：基础结果免费，AI 生成的个性化深度分析收费（9.9-19.9 元）
3. **社交裂变**：分享给朋友解锁额外内容
4. **企业版 / API**：团队测试、招聘场景（长期）

## 5. 综合建议

### 推荐路径（快 → 慢）

**第一步：微信小程序版 ABTI**（最快切入）
- 用小程序（非小游戏类目）发布，避免游戏审核
- 走"测试工具"类目，审核快
- 个人主体可发布（但不能收费），企业主体可开通支付
- 社交裂变是主要增长引擎

**第二步：抖音小程序 + 短视频引流**
- 拍"AI 人格测试"相关短视频
- 视频挂载小程序链接
- 需要企业资质

**第三步：小红书内容引流**
- 发测试类笔记 → 引导到微信小程序
- 零成本，纯内容运营

### 风险点
1. **企业主体**：微信个人主体不能开通支付，要变现需要企业
2. **域名备案**：微信小程序后端必须 ICP 备案域名 + HTTPS，我们的域名在海外服务器可能需要处理
3. **内容合规**：AI/心理测试类可能触及"心理咨询"资质审核，需要注意措辞（说"趣味测试"而非"心理测评"）
4. **抽成**：如果走微信支付，手续费仅 0.6%（低）；如果走游戏虚拟支付，抽成 40%+（高）
5. **AI 生成内容监管**：国内对 AI 生成内容有合规要求，需要标注"AI 生成"

### 关键决策点（需要 Luna 判断）
- [ ] 是否有企业主体可用？（影响能否变现）
- [ ] kagura-agent.com 是否已 ICP 备案？（影响能否上微信小程序）
- [ ] 是否愿意用 Luna 个人身份注册小程序？（最快但有限制）
- [ ] 变现优先级：先跑量（免费+广告）还是先验证付费意愿（收费报告）？
