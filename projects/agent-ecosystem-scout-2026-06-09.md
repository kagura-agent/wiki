# Agent Ecosystem Scout — 2026-06-09

## Key Findings

### 1. Star Velocity Update — Verification & Design Tools Accelerating
- **baoyu-design**: 363→549⭐ (+186 in 1 day). Claude Design extraction as local skill continues explosive growth.
- **guard-skills**: 347→474⭐ (+127 in 1 day). Quality gates for AI-generated code. Verification layer is now a product category.

Both projects validate the June 4-8 trend: the ecosystem is investing heavily in **post-generation quality** (verification, design, testing) rather than more generation capability.

### 2. codex-chatgpt-control — Cross-Surface Agent Bridging (NEW)
**adamallcock/codex-chatgpt-control** (161⭐, 3 days): Unofficial SDK for Codex agents to control visible ChatGPT web sessions. JS+Python dual SDK. Plan-based execution with structured blockers.

**Signal**: Cross-surface bridging (agent A drives product surface B) is a new pattern. People want agents to consult other agents/surfaces without manual tab-switching. Deep read: [[codex-chatgpt-control]].

### 3. Broader Ecosystem — No New Breakout Frameworks
GitHub API search for new ai-agent repos (>20⭐, created since June 6) returned only 3 results beyond the already-tracked baoyu-design and guard-skills. The MCP space produced zero new repos above threshold.

- **DeepX** (RainyMarks, 41⭐, Rust): "AI agent workspace" — too early/vague
- **Agnes-help-skill** (34⭐): Skill for accessing Agnes model API — niche
- **FerroxLabs/wayland-core** (15⭐, Rust): Multi-provider AI agent CLI — too small

### 4. Established Ecosystem Players — Active But Stable
- **hermes-agent**: 187K⭐, actively pushed
- **headroom**: 19K⭐, context compression (already tracked)
- **multica**: 35K⭐, managed agents platform
- **cherry-studio**: 47K⭐, AI productivity studio

No major architectural shifts or new releases from established players.

## Ecosystem Temperature

**Consolidation deepens**. The market is now clearly in a **tooling & verification** phase:
- Generation capability → commoditized (everyone has it)
- Verification, quality gates, design → the active investment area
- Cross-surface bridging → emerging demand signal (codex-chatgpt-control)
- New frameworks → near-zero traction. The framework wars are over; the tooling wars have begun.

**Money and attention flow**: towards making existing agents more reliable and more connected, not towards building new agent architectures.
