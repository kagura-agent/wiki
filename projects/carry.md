# Carry

Luna's VS Code extension project for OpenClaw integration.

## Goal

A VS Code extension focused on deep OpenClaw-specific features (cron, skills, memory) rather than multi-backend breadth.

## Design Direction (from Junction study)

- **Adopt**: checkpoint/rewind concept (shadow git) from Junction
- **Differentiate**: go deeper on OpenClaw-specific features rather than multi-bridge breadth
- **Avoid**: animation bloat — utility-first approach
