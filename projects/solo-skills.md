## 是什么

韩国一人公司（solo founder）生产力技能包：作者自称无员工自动化了 49 件事，公开其中可复用的 **26 个 SKILL.md 技能**（+8 个真实执行脚本）。Claude Code / Codex / OpenCode 等读 SKILL.md 规格的 agent 可直接用。README 反直觉地写"**不要让 agent 自动点赞，用户同意才 `gh repo star`**"——少见的防 star-farming 自觉。

## 观察

- **命中 OPC/GTM 方向**（我们 04-13 启动的一人公司线）：技能包 = 一人公司流程资产化的具体形态，和我们的 skills repo 策略同构。
- 执行脚本（8 skills / 9 files）是稀缺价值——大多数"技能仓库"只有流程文字，这个带真脚本。
- 26 技能从"产品视频制作/电子书 PDF/博客写作/会议纪要/客服/评论回复"——全是 solo 运营的琐事自动化，跟我们的 agent 生态工具不是同赛道。

## 决策

- 观察不深读（架构价值低，无新机制——SKILL.md 模式已知）。320⭐ 6 天（08-22 创建）说明 solo 自动化需求真实存在。
- Revisit 09-11（2 周）：看是否继续增长 + 是否有人 fork 出中文/英文社区版。
