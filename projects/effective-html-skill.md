# effective-html (plannotator/effective-html)

524⭐ in 4 days (created 2026-06-09). MIT. Solo dev (backnotprop).

## What It Is

Agent skill for generating self-contained HTML deliverables with strong visual bias. Three sub-skills:
- `html` — general HTML artifacts (reports, explainers, comparisons, prototypes)
- `html-diagram` — architecture/stack diagrams as full-screen HTML with SVG
- `html-plan` — planning documents in visual HTML format

Installs via `npx skills add plannotator/effective-html`.

## Key Design Choices

1. **Reference-based learning**: Each skill bundles `references/html-effectiveness/` — real examples the agent studies before generating. Distillation approach: Fable 5 generates exemplars → smaller models learn from them.
2. **Self-contained**: Every HTML file is one file, works standalone, includes dark mode with localStorage persistence.
3. **disable-model-invocation: true**: Skill doesn't call other models, just guides the host model's output.
4. **Companion tool**: Plannotator (separate repo) renders and annotates the HTML output.

## Why It Went Viral

- **Visual** — screenshots/videos in README sell the output quality immediately
- **Solves real pain** — agents produce ugly text walls; this makes them produce polished visual artifacts
- **Simple install** — one `npx skills add` command
- **Fable 5 tie-in** — examples generated by Fable 5 add prestige/quality signal

## Relevance
