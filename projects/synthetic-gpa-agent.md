## What it is—and is not

This is a small reproducible benchmark for dual-reflection geometric phase analysis (GPA), not a general scientific agent. It synthesizes a two-cosine lattice with a known smooth displacement field, applies Gaussian Fourier masks around two nonparallel reciprocal vectors, removes their carrier phases, solves the two-component displacement proxy, and scores it against the generated truth.

Its unusually explicit boundary is load-bearing: synthetic outputs cannot identify a real Burgers vector, individual dislocation, GND density, material boundary, or deformation mechanism. The optional OpenAI agent can invoke only `run_bounded_benchmark(size, noise_std, seed)`; that function limits size to 48–512 and noise to 0–0.30, then writes a deterministic demo. The agent instruction repeats the same real-material prohibition.

## Tests establish the mechanism, not scientific validity

The test suite checks deterministic generation, input bounds, nonparallel-reflection rejection, recovery on one generated configuration (centered `ux` RMSE <0.15 pixels; `exx` correlation >0.90), artifact emission, and presence of synthetic-only language in the agent tool output. This is a meaningful minimum: the numerical pipeline has an oracle and the disclosure boundary is executable rather than README-only.

But the oracle is self-generated by the same narrow model being evaluated. The single open roadmap issue asks for a sensitivity matrix across mask radius, noise/scan distortion, reflection-angle separation, and reference regions—the exact missing test surface. No real microscopy data, independent reproduction, uncertainty calibration, or adversarial boundary test was found.

## Position in the agent ecosystem

Alongside [[research-evidence-agent]] and `engineering-run-agent`, it is part of a single-author portfolio of narrow, bounded “agent” wrappers. Where research-evidence-agent mechanically blocks claims whose evidence class is too weak, this project makes the **data-generating scope** and **tool parameter range** explicit. It is a useful counterexample to the common pattern of adding a model after the fact: here the model has no authority to expand an underlying numerical result into a domain claim.

It complements [[eval-driven-self-improvement]] and [[agent-memory-benchmark]]: an evaluation loop only has epistemic value when its metric comes from an oracle independent enough to falsify the system being changed. This repository achieves reproducibility within its synthetic world, but not independence from that world.

## Transferable lesson for our workflows

For an optional model reviewer, expose a bounded deterministic tool and make its output carry a machine-checkable scope statement. Treat any conclusion that crosses from synthetic/test data to operational reality as a separate, human-reviewed evidence class. That is more robust than prompt wording alone—but the tool boundary must be paired with a stress suite that varies the assumptions it depends on.

No adoption is proposed: GPA/scientific-method-card functionality is outside our current operational needs. The relevant pattern is the combination of parameter bounds, deterministic artifacts, truth-based checks, and an explicit no-inference boundary.
