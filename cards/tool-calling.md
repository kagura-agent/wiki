# Tool Calling

LLM capability to invoke external tools and functions with structured parameters and results. The [[mcp-ecosystem]] standardizes tool discovery and transport, while [[tool-shapes-behavior]] explores how available tools influence model reasoning. Effective tool calling requires [[observability]] to track invocation costs and failure rates.
