Smart routing refers to adaptive model selection and request routing strategies for LLM interactions. Related to [[semantic-model-routing]] for intent-based dispatch, [[token-efficiency]] optimization, and [[ffn-free-routing]] architectures. Relevant developments include Microsoft's MAI-Code-1-Flash, an efficiency-focused coding model that achieves 60% fewer tokens than Claude Haiku 4.5 through model-level adaptive solution length control, demonstrating that routing decisions can optimize for both cost and quality.
