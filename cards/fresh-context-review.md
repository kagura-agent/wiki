# Fresh-context review

A technique that spawns Claude Code in read-only mode to review diffs from clean context without prior session history. A form of [[diff-scoped-review]] that avoids [[context-rot]]. [[gauntlet-loop|Gauntlet Loop]] applies the same separation to a builder/critic comparison, but needs a bounded stop condition and independently checkable evidence.
