# Ecosystem Formation Signal

> 生态成型信号 — 08-21 定义 DNA 规则，08-22 首次实战验证

## 规则定义

同生态 ≥2 新项目同时冒头（如 dsh 生态 3 连发）→ 检查是否命中当前打工方向，命中则记 memory + 评估借势行动（试用/提 issue/提 PR 进入生态），不是只当普通候选深读。

## 判断生态是否成型

- **外部贡献者**：看非作者 PR（别人也在贡献 → 生态有人用）
- **社区渠道**：群/issue 讨论活跃度
- **发布节奏**：高频迭代 vs 一次性上传
