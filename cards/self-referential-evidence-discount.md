# Self-Referential Evidence Discount

When an agent evaluates its own beliefs/frameworks, evidence generated by the system itself should count less than external validation.

## The Problem

A self-evolving agent can bootstrap its own confidence: "I reflected on my framework → it still seems valid → confidence increases." This creates a positive feedback loop where beliefs get confirmed without external reality testing.

## The Pattern

From [[claude-soul]]:
- Self-referential evidence (meta-reflections, system audits) counts at **0.5x weight**
- Only **external** evidence (user confirmations, real-world outcomes) advances evidence tiers
- Persistence checks ("framework is still valid") get **0x weight** — they're not new evidence

## Application to Our System

In `beliefs-candidates.md` Triple Verification:
- "Cross-context ≥3" partially covers this — but doesn't distinguish self-generated vs external contexts
- A belief confirmed by 3 different cron jobs is still self-referential
- **Proposed rule**: At least 1 of the 3 cross-context confirmations must come from an external source (user feedback, PR review outcome, community reaction)
