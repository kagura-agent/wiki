# Subagent

Ephemeral worker agents spawned for specific tasks with isolated context and session state. See [[subagent-usage-patterns]] for common dispatch strategies and [[delegating-executor-pattern]] for the parent-child coordination model. Subagents benefit from [[git-worktree-isolation]] when making parallel file changes.
