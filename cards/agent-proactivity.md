# Agent Proactivity

The trend toward agents that actively propose work and suggestions rather than waiting passively for instructions. Sits within the spectrum of [[agent-autonomy-models]], often using [[heartbeat]] mechanisms to trigger unprompted actions. Closely related to [[agent-self-evolution]] where proactive behavior extends to self-improvement.
