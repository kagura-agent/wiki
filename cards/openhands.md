# OpenHands

Open-source AI coding agent platform (formerly OpenDevin) by All-Hands-AI on GitHub. Provides isolated Docker-based execution environments for AI agents to perform software development tasks. Part of the broader [[coding-agent-ecosystem]] and comparable to tools in the [[agent-harness-landscape]]. Its sandboxed execution model relates to [[agent-isolation]] principles.
