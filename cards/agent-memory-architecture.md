# Agent Memory Architecture

Architectural patterns for agent memory systems including hooks, retrieval, and state management. Builds on [[agent-memory]] primitives, often implemented via [[memory-read-write-loop-hooks]], with [[contrastive-memory]] as an emerging retrieval technique. [[memory-forest]] applies these patterns to structured, tree-based memory organization with sweep-based consolidation.
